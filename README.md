# Advanced Programming Lab

This repository contains a collection of assignments and exercises from the **Advanced Programming Lab** course. The projects cover Java concepts ranging from basics to complex GUI application development.

## 🚀 Repository Structure

The repository is organized into two main sections:

### 1. Codelab
Weekly focused exercises to deepen the understanding of Java programming concepts.
- `Codelab_1` to `Codelab_6`

### 2. Demo (Tasks)
Independent projects or final assignments applying concepts learned in the Codelabs.
- `Tugas_1`: Java basics, Input/Output, and Exception Handling.
- `Tugas_2` to `Tugas_5`: Implementation of various features and data structures.
- `Tugas_6`: Temperature Converter application built with Java Swing, featuring Login, Registration, and Data History (CSV).

## 🛠️ Requirements
- **Java Development Kit (JDK)**: Version 11 or later (JDK 17+ recommended).
- **IDE**: IntelliJ IDEA (recommended) or any Java-compatible IDE (NetBeans/Eclipse).

## ⚙️ How to Run
1. Clone this repository.
2. Open the specific project folder in IntelliJ IDEA.
3. Ensure the Java SDK is correctly configured in your IDE.
4. Run the `Main` or `AppMain` class located in the `src` directory.
